# RespawnPoints — Roadmap

Серверный конфиг: `config/respawnpoints-server.json`
(`bedLimit`, `nearDeathRadius`, `nearDeathMinDistance`;
перезагрузка без рестарта: `/respawnpoints admin reload`).
DeathScreen при неизвестном источнике смерти: сразу наш экран выбора.

## 1. Варпы: скоуп и приватность

- [ ] **Локальные / глобальные варпы**
  - Новое поле скоупа в `WarpPoint` (`LOCAL` — виден только в своём измерении,
    `GLOBAL` — виден везде). Дефолт для старых записей: `GLOBAL` (без миграции).
  - Флаг в команде создания (`/respawnpoints warp add <name> [--local]`).
  - Фильтр по скоупу в `DeathManager.buildEntries()` (единственная точка фильтрации).
  - Отображение скоупа в `XaeroRespawnScreen` и `RespawnSelectScreen`.
  - `id`-схема `warp:<slug>` не меняется (на неё завязаны синки карт).
- [ ] **Приватные варпы для группы игроков**
  - Поля `owner` / `group`, команды управления группой (создание, инвайт, кик,
    удаление). Дефолт: `PUBLIC`.
  - Фильтрация строго на сервере в `buildEntries()` (список едет клиенту —
    приватность нельзя делать клиентским фильтром).
  - Краевые случаи: удаление группы, кик офлайн-игрока, удаление варпа владельцем.
  - Оценка: самая крупная фича, делать по фидбеку после релиза — возможно, не понадобится.

## 2. Ванильный фолбэк после анбинда (записано, пока не чинить)

- [ ] **Баг 1: отвязанная кровать воскресает через ваниллу.**
  Спавн и near-death выключены, других меток нет, у игрока одна кровать →
  админ отвязывает (`bed list` — «нет привязанных») → на смерти тост
  «точек нет» → клик → ванилла везёт на последнюю привязанную кровать
  (ванильный `respawnPosition` никто не чистил: `onDelete`/`adminUnbind`
  чистят только реестр+снапшот), тост при этом обещает мировой спавн.
  Наблюдение со скрина: после ванильного респауна кровать снова в нашем
  списке с тем же id — гипотеза: ванильный респаун дёргает
  `setRespawnPosition(forced=false)` и наш `MixinServerPlayerSpawnTracking`
  перепривязывает. Проверка при фиксе: debug в миксин на респауне.
  Варианты фикса: **A** — гасить ванильную точку при анбинде, если она
  совпадает с отвязываемой (рекомендуется автором мода); **B** — пустой
  оффер всегда везти на мировой спавн нашим путём вместо passthrough;
  **C** — оставить поведение, поправить текст тоста на честный.
- [ ] **Баг 2: то же с якорем в аду.**
  Заряженный якорь, точек нет → ванилла везёт к якорю и жрёт заряд мимо
  реестра. Тот же корень, тот же фикс (A покрывает оба). Нюанс: заряд
  в блоке остаётся; при повторной привязке заряды перечитаются с блока.
- [ ] **Stale `hasEmptyOffer` (парк, руками не воспроизводится).**
  Пустой оффер ставит флаг, который никто не сбрасывает (тик-свип его не
  видит, `disarm`/`updateLive` не чистят) → теоретически смерть2 с кликом
  до нового оффера даст ложный мгновенный ванильный проход мимо селекта.
  На локалке не ловится (окно ≈ RTT). Дешёвое hardening на потом: сброс
  флага на открытии `DeathScreen` + в живом тике по `ARM_GRACE`.

## 3. Дальше (идеи, без обязательств)

- [ ] Переработка near-death (дефолт `showNearDeath` выключен до неё):
  текущему полярному семплингу не хватает дальности без догрузки чанков
  (кольца 256–512 при вью ~160 дают фолбэк на труп); см. отложенный план
  «Умный дальний поиск» ниже.
- [ ] Схема «разряженное — мимо селекта» (текущее решение, может поменяться):
  если все записи оффера — якоря с 0 зарядов, экран выбора не открывается,
  клик сразу идёт в ваниллу. Кандидат на будущее: серый список с кнопкой
  удаления вместо пропуска.
- [ ] JourneyMap — дормант, не удалён: код синка, enum, lang-ключи и выбор
  лежат на месте, из UI убрано (мод пока только с Xaero). Возврат: вернуть
  кнопку/категорию и `JOURNEYMAP` в резолв.
- [ ] Поиск по имени + фильтр по типу на экранах + закрепы точек и drag-sorting
  закрепов (убран из текущей сборки: поле ввода перехватывало хоткеи Xaero —
  `U/Y/M` работали на экране смерти, `M` закрывал меню; вернуть только вместе
  с гашением чужих кейбиндов).
- [ ] `ru_ru.json` (русская локализация).
- [ ] Цвет в экране переименования (не только из меню карты).
- [ ] Лимит варпов на игрока / кулдауны варпов.
- [ ] Публичный API для мап-модов (свой формат меток вместо adopt-by-position).
- [ ] Rename точек прямо с экрана смерти: кнопка на карточке → существующий
  `RenamePointScreen` → возврат с сохранением выбора.
- [ ] Умный дальний поиск NEAR_DEATH (отложено): ставки вместо сканирования —
  2–3 дальние точки вслепую (сдвиг вдаль, разброс высоты вверх), проверка максимум
  1–2 чанков через общую очередь (2 загрузки/тик на сервер), только память
  (никакой догрузки непрогруженного), фолбэк у трупа; single-R вместо пары min/max.
- [ ] Живой тест сборок с Create/Aeronautics: contraption на привязанной кровати
  (ожидаем: блок не захватывается, `non_movable` тег на месте); сон на корабле
  + смерть после перелёта (ожидаем: точка пишется, после уплытия честно битая).
